[DEUTSCH]  (English below)

WAS IST DAS?
GK2 Vanilla+ macht Graveyard Keeper 2 angenehmer, ohne das Spiel zu verändern:
kein anderes Gameplay, keine Spieldateien angefasst, Spielstände bleiben mit
dem Originalspiel kompatibel. Jede Funktion lässt sich einzeln abschalten
("Alles aus (Vanilla)" im Mod-Menü).
- Komfort: Rezepte, Baupläne, Aufträge, Quests anpinnen (Haben/Brauchen-Liste),
  Max-Knopf beim Herstellen, passende Menge beim Handeln, Zombies umbenennen,
  Wochenplan, schnellere Türen und Reisen.
- Leistung: versteckte Grafikoptionen, Profile (Steam Deck, Leistung,
  Qualität), FPS-Limit/VSync, Benchmark, FPS-Anzeige.
- Bild: Ultrawide 21:9 und 32:9, eigene Hauptmenü-Hintergründe, Kamera-Zoom,
  Screenshots in bis zu 4-facher Auflösung.
- Spielstände: Übersicht im Hauptmenü, automatische Backups mit
  Wiederherstellen, wichtige Backups behalten (auch vor Kämpfen gesichert).
- Komplett mit dem Controller bedienbar (Steam Deck).

INSTALLATION (Windows)
1. Steam Workshop: "Abonnieren" und warten, bis Steam es geladen hat.
   Den Ordner öffnen: <Steam-Bibliothek>\steamapps\workshop\content\4358690\3808053878
   GitHub: ZIP-Datei komplett entpacken (Rechtsklick > "Alle extrahieren").
2. "Installieren.bat" doppelklicken. Falls Windows warnt ("Der Computer wurde
   durch Windows geschützt"): "Weitere Informationen" > "Trotzdem ausführen".
3. Der Spielordner wird automatisch gefunden. Falls nicht: "Durchsuchen" und
   den Ordner wählen, in dem GraveyardKeeper2.exe liegt
   (Steam: Rechtsklick auf das Spiel > Verwalten > Lokale Dateien durchsuchen).
4. Version wählen:
   - Stabil (empfohlen): getestete Version, direkt aus diesem Paket.
   - Beta: neueste Vorabversion von GitHub mit neuen Funktionen; kann Fehler
     enthalten. Den Kanal kannst du später im Mod-Menü unter "Update-Kanal"
     ändern.
5. "Installieren" klicken und das Spiel ganz normal über Steam starten.

IM SPIEL
- F9  = Mod-Menü (oder Knopf "Vanilla+" im Haupt- und Pausenmenü)
- F10 = FPS-Anzeige    F6  = Wochenplan    F7  = HUD ausblenden
- F5  = Zoom-Stufen    F12 = Screenshot in hoher Auflösung
- Anpinnen: Linksklick auf die kleine Nadel neben Rezepten, Aufträgen und
  Bauplänen. Im Mod-Menü kannst du stattdessen eine Taste oder Maustaste
  festlegen. Controller: RT halten, um die Liste zu bedienen.
- Ultrawide-Auflösung: Einstellungen > Grafik > Auflösung.
- Jede Option im Mod-Menü hat eine Erklärung, wenn du darauf zeigst.

AKTUALISIEREN
Im Spiel zeigt das Mod-Menü (F9) neue Versionen an: "Speichern & aktualisieren".
Oder "Installieren.bat" starten > "Online nach Updates suchen".
Deine Einstellungen bleiben dabei erhalten.

DEINSTALLIEREN
"Installieren.bat" starten > "Deinstallieren" und wählen:
- "Alles entfernen": Vanilla+ und BepInEx (Mod-Loader), das Spiel ist wieder
  original. Ohne andere Mods ist das die richtige Wahl.
- "Nur Vanilla+": BepInEx und andere Mods bleiben.
Backups und Screenshots des Mods werden nach Dokumente\GK2 Vanilla+ gerettet,
dort liegt auch ein Protokoll (uninstall.log). Deine Spielstände bleiben
spielbar. Steam-Workshop: zusätzlich "Deabonnieren".

MAC (CrossOver) / LINUX / STEAM DECK (Proton)
Den Inhalt von "installer/files" in den Spielordner kopieren und einmalig die
DLL-Überschreibung "winhttp" auf "nativ, builtin" stellen
(CrossOver: Flasche > Wine-Konfiguration > Bibliotheken;
Proton: Startoption WINEDLLOVERRIDES="winhttp=n,b" %command%).
Eine bebilderte Anleitung steht im Steam Workshop im Diskussionen-Tab.

PROBLEME?
Log-Datei: <Spielordner>\BepInEx\LogOutput.log – bitte mitschicken
(Steam Workshop > Diskussionen oder GitHub > Issues).


[ENGLISH]

WHAT IS THIS?
GK2 Vanilla+ makes Graveyard Keeper 2 more comfortable without changing the
game: no gameplay changes, no game files touched, saves stay compatible with
the unmodded game. Every feature has its own switch ("All off (vanilla)" in
the mod menu).
- Comfort: pin recipes, blueprints, orders and quests (have/need list),
  Max button when crafting, the right amount when trading, rename zombies,
  week plan, faster doors and travel.
- Performance: hidden graphics options, profiles (Steam Deck, Performance,
  Quality), FPS cap/VSync, benchmark, FPS display.
- Screen: ultrawide 21:9 and 32:9, custom main menu backgrounds, camera zoom,
  screenshots in up to 4x resolution.
- Saves: overview in the main menu, automatic backups with restore, keep
  important backups (also saved before battles).
- Fully playable with a controller (Steam Deck).

INSTALL (Windows)
1. Steam Workshop: click "Subscribe" and wait until Steam has downloaded it.
   Open the folder: <Steam library>\steamapps\workshop\content\4358690\3808053878
   GitHub: extract the whole ZIP (right click > "Extract All").
2. Double-click "Installieren.bat". If Windows SmartScreen warns:
   "More info" > "Run anyway".
3. The game folder is found automatically. If not, click "Browse" and pick the
   folder containing GraveyardKeeper2.exe
   (Steam: right click the game > Manage > Browse local files).
4. Choose a version:
   - Stable (recommended): tested version, straight from this package.
   - Beta: newest pre-release from GitHub with new features; may contain
     bugs. You can change the channel later in the mod menu under
     "Update channel".
5. Click "Install", then start the game normally via Steam.

IN GAME
- F9  = mod menu (or the "Vanilla+" button in the main and pause menu)
- F10 = FPS display    F6  = week plan     F7  = hide HUD
- F5  = zoom presets   F12 = hi-res screenshot
- Pinning: left click the small pin next to recipes, orders and blueprints.
  In the mod menu you can use a key or mouse button instead.
  Controller: hold RT to control the list.
- Ultrawide resolution: Settings > Graphics > Resolution.
- Every option in the mod menu explains itself when you point at it.

UPDATE
In game the mod menu (F9) shows new versions: "Save & update".
Or run "Installieren.bat" > "Check online for updates". Your settings are kept.

UNINSTALL
Run "Installieren.bat" > "Uninstall" and choose:
- "Remove everything": Vanilla+ and BepInEx (mod loader), the game is back to
  original. Without other mods this is the right choice.
- "Vanilla+ only": BepInEx and other mods stay.
The mod's backups and screenshots are moved to Documents\GK2 Vanilla+, along
with a log (uninstall.log). Your saves keep working.
Steam Workshop: also click "Unsubscribe".

MAC (CrossOver) / LINUX / STEAM DECK (Proton)
Copy the contents of "installer/files" into the game folder and set the DLL
override "winhttp" to "native, builtin" once
(CrossOver: bottle > Wine configuration > Libraries;
Proton launch option: WINEDLLOVERRIDES="winhttp=n,b" %command%).
A step-by-step guide is pinned in the Steam Workshop Discussions tab.

PROBLEMS?
Log file: <game folder>\BepInEx\LogOutput.log – please include it
(Steam Workshop > Discussions or GitHub > Issues).

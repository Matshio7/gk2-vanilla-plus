Native = world at full resolution. Lightweight = world at half resolution (chunkier pixels), much less GPU load. Default = as the graphics tier. => 原生 = 世界以完整分辨率渲染。轻量 = 世界以一半分辨率渲染（像素更粗），显卡负载大幅降低。默认 = 跟随画质档位。
Shadows. NGSS = soft PC shadows (expensive). Unity_* = simpler shadows as on PS5/Xbox. Default = as the graphics tier. => 阴影。NGSS = PC 柔和阴影（开销大）。Unity_* = 与 PS5/Xbox 相同的简单阴影。默认 = 跟随画质档位。
Ambient occlusion (HBAO). Off is otherwise only used on Switch. Default = as the graphics tier. => 环境光遮蔽（HBAO）。“关”原本只在 Switch 上使用。默认 = 跟随画质档位。
Point lights real (Realtime) or simulated (Faked, cheaper). Default = as the graphics tier. => 点光源为真实光照或模拟光照（开销更低）。默认 = 跟随画质档位。
Back light effect. Default = as the graphics tier. => 逆光效果。默认 = 跟随画质档位。
Water quality. Default = as the graphics tier. => 水面质量。默认 = 跟随画质档位。
Clouds normal or simplified. May apply only after changing area. Default = as the graphics tier. => 普通或简化的云。可能在切换区域后才生效。默认 = 跟随画质档位。
Game = setting from the game menu. Limit = software cap at TargetFps. VSync = synced to the refresh rate (60 FPS at 120 Hz = every 2nd refresh). => 游戏 = 使用游戏菜单中的设置。限制 = 用软件把帧率限制在目标 FPS。垂直同步 = 与刷新率同步（120 Hz 下 60 FPS = 每两次刷新一帧）。
Target FPS for Limit and VSync. 0 = unlimited => 限制与垂直同步的目标 FPS。0 = 无限制
Physics rate. 0 = game default (50 Hz). 30 = like the Switch version, saves CPU. => 物理频率。0 = 游戏默认（50 Hz）。30 = 与 Switch 版相同，节省 CPU。
What the game writes to Player.log. Warning or Error suppresses log spam. => 游戏写入 Player.log 的内容。选“警告”或“错误”可减少日志刷屏。

[EN] INSTALL
Easiest: download the installer from GitHub (link above, "Releases") -
it sets up everything with one click and can update the mod later.

Manual install from this Workshop item:
1. Install BepInEx 5.4.23.5 x64 in the game folder (next to GraveyardKeeper2.exe):
   https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5
2. Copy the "BepInEx" folder from this item into the game folder (merge folders).
3. Start the game and press F9 for the mod menu.
Uninstall: delete BepInEx\plugins\GK2Tweaks and BepInEx\plugins\GK2Ultrawide.

[DE] INSTALLATION
Am einfachsten: den Installer von GitHub laden (Link oben, "Releases") -
richtet alles mit einem Klick ein und kann den Mod spaeter aktualisieren.

Manuell aus diesem Workshop-Item:
1. BepInEx 5.4.23.5 x64 in den Spielordner installieren (neben GraveyardKeeper2.exe):
   https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5
2. Den Ordner "BepInEx" aus diesem Item in den Spielordner kopieren (zusammenfuehren).
3. Spiel starten, F9 oeffnet das Mod-Menue.
Deinstallieren: BepInEx\plugins\GK2Tweaks und BepInEx\plugins\GK2Ultrawide loeschen.

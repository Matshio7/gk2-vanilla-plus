=== GUIDE TITLE
GK2 Vanilla+ – ultrawide, more FPS and small comforts, without changing the game

=== GUIDE DESCRIPTION
Setup and tour of GK2 Vanilla+: ultrawide 21:9 / 32:9, hidden graphics settings for weak PCs, laptops and the Steam Deck, pinned recipes with have/need, a week plan and save backups. No balance changes, no spoilers, your saves stay vanilla.

=== SECTION: What this guide is
Graveyard Keeper 2 is a lovely game with a few rough edges around it: black bars on wide monitors, graphics options that only come as four fixed tiers, and recipes you have to keep in your head while you walk to the chest.

[b]GK2 Vanilla+[/b] smooths those edges – and nothing else. This guide shows how to install it (Windows, Steam Deck / Linux, Mac) and what each part does.

[b]What it does not do:[/b]
[list]
[*]No balance changes – no prices, recipes, drop rates, speeds or difficulty are touched.
[*]No spoilers – the week plan and all lists only show what your own save has already unlocked.
[*]No game files are modified, and your save files are never written by the mod. Remove it and the game is exactly as before.
[/list]

Everything is optional: every feature can be switched on or off in the in-game mod menu.

=== SECTION: Step 1 – Install (Windows)
Graveyard Keeper 2 has no built-in mod loader, so [b]Subscribe[/b] alone only downloads the files. Installing takes one minute and only has to be done once.
[olist]
[*]Click [b]Subscribe[/b] on the [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3808053878]Workshop page[/url] and wait until Steam has downloaded it.
[*]Open the mod folder:
[i]<Steam library>\steamapps\workshop\content\4358690\3808053878[/i]
(by default [i]C:\Program Files (x86)\Steam\steamapps\workshop\content\4358690\3808053878[/i])
[*]Double-click [b]Installieren.bat[/b]. If Windows says "Windows protected your PC": [b]More info[/b] → [b]Run anyway[/b] – the script just isn't signed.
[*]The game folder is found automatically → [b]Install[/b].
[*]Start the game normally through Steam. The main menu now has a [b]Mods[/b] button, and [b]F9[/b] opens the same menu anywhere.
[/olist]
The installer also sets up [b]BepInEx 5.4.23.5[/b], the standard Unity mod loader. If you already use other BepInEx mods, nothing changes for them.

[b]Prefer Nexus or doing it by hand?[/b] The Nexus file is a plain archive without any scripts: unpack it straight into the game folder (Steam → right-click the game → Manage → Browse local files), so that [i]BepInEx[/i], [i]winhttp.dll[/i] and [i]doorstop_config.ini[/i] sit next to [i]GraveyardKeeper2.exe[/i].

=== SECTION: Step 1 – Install (Steam Deck / Linux, Mac)
[b]Steam Deck / Linux (Proton)[/b] – on the Deck, do this in Desktop Mode.
[olist]
[*]Subscribe and let Steam download the mod.
[*]Open [i]~/.local/share/Steam/steamapps/workshop/content/4358690/3808053878/installer/files[/i] (hidden folders: Ctrl+H).
[*]Open the game folder: right-click Graveyard Keeper 2 → Manage → Browse local files.
[*]Copy [b]everything inside[/b] "files" into the game folder, next to [i]GraveyardKeeper2.exe[/i].
[*]Right-click the game → Properties → Launch Options:
[code]WINEDLLOVERRIDES="winhttp=n,b" %command%[/code]
[*]Start the game – the [b]Mods[/b] button in the main menu means it works.
[/olist]

[b]Mac (CrossOver)[/b]
[olist]
[*]Subscribe in the Steam client inside your bottle.
[*]Copy everything from [i]…/steamapps/workshop/content/4358690/3808053878/installer/files[/i] into [i]…/steamapps/common/Graveyard Keeper 2[/i].
[*]Once per bottle: Wine Configuration → Libraries → add [i]winhttp[/i] → Edit → [b]Native then Builtin[/b].
[/olist]

[b]Controller stutter?[/b] Under Linux and on Mac, PlayStation controllers can cause small hitches in some setups. The mod menu has a [b]controller fix[/b] for that (section "Mac / Linux").

=== SECTION: The mod menu (F9)
Everything lives in one menu that looks like it belongs to the game: press [b]F9[/b], or click [b]Mods[/b] in the main or pause menu.
[list]
[*][b]Hover any option[/b] and the bottom of the menu explains what it does.
[*][b]Controller:[/b] D-pad or left stick to select and change, [b]A[/b] to confirm, [b]B[/b] or [b]Start[/b] to close. While a mod window is open, the game ignores the controller.
[*][b]Profiles:[/b] one click for [i]Steam Deck / battery[/i], [i]Performance[/i], [i]Quality[/i] or back to [i]Game default[/i]. Afterwards every single option stays adjustable.
[*]6 languages (English, German, French, Spanish, Russian, Chinese), a high-contrast mode and an adjustable menu size.
[/list]
Settings are saved immediately and survive updates. Nothing has to be edited in config files.

=== SECTION: Ultrawide – no more black bars
On a 21:9 or 32:9 monitor the game offers only 16:9 resolutions and leaves you with two thick black bars – and rain and snow stop halfway across the screen.

With Vanilla+ the game lists your real resolution (2560×1080, 3440×1440, 3840×1080, 5120×1440 and more) in its own graphics settings. The world fills the whole screen, the main menu fills the sides with a soft, blurred copy of its picture, and [b]rain and snow cover the full width[/b] – also when you zoom out.

[b]HUD to the center[/b] (optional): on very wide screens the HUD sits far out in the corners. This moves it – plus the area name, the NPC window and the mod's own displays – into the 16:9 area in the middle, while the world stays ultrawide.
[IMAGE: 15_full_width_rain.jpg]

=== SECTION: More FPS – for weak PCs, laptops and the Steam Deck
The game has four graphics tiers. Internally it has many more switches – they just aren't in the options.

The mod menu makes them available one by one: shadows, ambient occlusion, point lights, back light, water, clouds and the render mode. Each one explains what it changes. Add an FPS cap or VSync with a target FPS and the physics rate, and a laptop that used to run hot and loud can run quiet – or a PC that stuttered can hold a steady 60.

[b]Not sure where to start?[/b] Use a profile (see the mod menu section) or run the [b]graphics benchmark[/b]: it runs through all four tiers for a bit over a minute, measures the FPS without a cap and recommends a tier. Nothing is changed – your settings stay exactly as they were.
[IMAGE: 04_graphics_benchmark.jpg]

=== SECTION: Pinning – what to bring with you
The workbench wants "2 planks, 3 copper parts, 8 polished stone". You walk to the chest and arrive with a head full of other numbers.

Click the [b]pin[/b] next to a recipe, a blueprint in the build menu, a town building, a blockage (like the tunnel breakthrough) or a quest. A small list at the screen edge now shows every ingredient as [b]have / need[/b], green when you have enough – or the current task of a pinned quest.
[list]
[*]Counts what you carry, and optionally [b]all chests on the map[/b].
[*]A short message with a sound when something is [b]ready[/b] to craft or build.
[*]Optional [b]auto-unpin[/b] when you start crafting it.
[*]Controller: press [b]both sticks[/b] (L3 + R3) on a recipe or quest.
[/list]
Pins are saved per save slot and never written into the save itself.

=== SECTION: Week plan and daily reminder
Every day of the week is good for something – but which one was the sermon day again?

[b]F6[/b] opens the week plan: what is possible on which weekday, today and tomorrow highlighted, with the game's own day icons. And each morning a short, optional message tells you what today is good for.

It is [b]spoiler-free[/b]: only things your save has already unlocked appear.

=== SECTION: Saves and backups
[list]
[*][b]Save overview[/b] in the main menu (inside the mod menu): all slots with day, graveyard and church rating, playable with one click – including the backup copies the game makes itself.
[*][b]Automatic backups[/b] of your save every few minutes, and a one-click [b]restore[/b] (with an extra safety backup before restoring).
[*][b]Save now[/b] – a button and an optional hotkey, and an extra autosave interval if you like.
[/list]
Backups are copies next to the mod, in [i]BepInEx\GK2VanillaPlus\Backups[/i]. Your original saves are only read, never changed. When you uninstall with Installieren.bat, backups and screenshots are moved to [i]Documents\GK2 Vanilla+[/i] instead of being deleted.
[IMAGE: 09_saves_backups.jpg]

=== SECTION: FPS display, camera and screenshots
[b]FPS display (F10)[/b] – pick the corner and what to show: FPS, 1% low, frame time, CPU, GPU, RAM, VRAM, GPU temperature (NVIDIA), resolution, clock, in-game weekday and time. Order and separator are up to you.

[b]Camera[/b] – zoom presets on [b]F5[/b], a separate zoom level indoors, and smooth zooming with the mouse wheel.

[b]Screenshots (F12)[/b] – up to 4× resolution, optionally without the HUD. [b]F7[/b] hides the HUD any time (Esc brings it back).

[b]OLED black[/b] – pure black instead of dark grey around the map, for OLED screens and dark rooms.

[b]Small things[/b] – pause when the game is in the background, skip the intro logos, and a short "What's new" after an update.

=== SECTION: Updates and safe mode
[b]Updating (Windows, Workshop version):[/b] when a new version is out, the mod menu shows [b]Save & update[/b] – one click, your settings are kept. Running Installieren.bat again works too. Note: Steam updating the Workshop item alone does not update the installed mod.
[b]Linux / Mac / Nexus:[/b] copy or unpack the new files over the old ones. Your settings stay.

[b]Safe mode:[/b] when Graveyard Keeper 2 itself gets an update, the mod checks everything it relies on at startup. If something changed, only that one feature switches itself off – with a note in the mod menu – instead of throwing errors. The rest keeps working, and the check runs again at every start, so the feature comes back as soon as it works again.

=== SECTION: Troubleshooting
[b]There is no Mods button in the main menu[/b]
BepInEx isn't loading. Check that [i]BepInEx[/i], [i]winhttp.dll[/i] and [i]doorstop_config.ini[/i] are directly next to [i]GraveyardKeeper2.exe[/i] – not inside an extra folder. On Steam Deck / Linux, check the launch option; on Mac, the winhttp DLL override.

[b]An error window pops up when switching between controller and mouse[/b]
Known issue: switching input devices while a menu is open can show an error message. Just close it – everything keeps working normally.

[b]A hotkey does nothing[/b]
Another program or overlay may be using it. Every hotkey can be changed in the mod menu (click the key, press a new one; B on a controller cancels).

[b]Something is broken[/b]
Please post in the [url=https://steamcommunity.com/sharedfiles/filedetails/discussions/3808053878]Bug Reports discussion[/url] and attach [i]BepInEx\LogOutput.log[/i] from the game folder. That file tells me almost everything.

[b]I want the game back exactly as before[/b]
Windows: Installieren.bat → [b]Uninstall[/b] (optionally removes BepInEx too). Linux / Mac: delete [i]BepInEx[/i], [i]winhttp.dll[/i], [i]doorstop_config.ini[/i] and [i]changelog.txt[/i] from the game folder. Your saves are never touched.
